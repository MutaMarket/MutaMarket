# API: фильтрация и сортировка

`GET /api/modules/{query}` принимает фильтры и сортировку как сегменты URL, а
не как параметры запроса. Эта страница является словарём; формы запросов и
ответов см. в [справочнике эндпоинтов](/documentation/api).

## Опции

Сегмент пути `query` **обязан** содержать опцию типа
(`type/{id-or-slug}`, например `type/49738` или
`type/abyssal-ballistic-control-system`) и принимает те же опции фильтрации,
что и браузер модулей, соединённые в цепочку сегментов URL в любом порядке.

| Опция | Формат | Эффект |
|---|---|---|
| sort | `sort/{field}/{direction}` | Сортировка по `price` (цена контракта), `value` (оценочная стоимость), `fraction` (среднее качество ролла), `contract-date` (когда был выставлен текущий контракт), `date-added` (когда текущий контракт модуля был добавлен на MutaMarket) или по атрибуту dogma по id или имени (`sort/50/desc`, `sort/cpu/asc`). Направление: `asc` или `desc`. Сортировка по атрибуту возвращает только модули, у которых он есть. |
| attributes | `attributes/{attribute}/{value}` (пары, повторяемые) | Фильтр по выпавшим значениям, например `attributes/cpu/20-30/damageMultiplier/2.1`. Диапазон `min-max` ограничивает значение; одиночное число является минимумом там, где большее значение лучше, иначе максимумом. |
| meta-group | `meta-group/{group}` | Одно из `t1`, `t2`, `storyline`, `faction`, `officer`, `deadspace`: только модули, мутированные из исходного модуля этой метагруппы. |
| meta-level | `meta-level/{n}` | Только модули, мутированные из исходного модуля этого метауровня. |
| contract-price | `contract-price/{max}` или `{min}-{max}` | Ограничивает цену контракта в ISK. |
| estimated-value | `estimated-value/{min}` или `{min}-{max}` | Ограничивает оценочную стоимость в ISK. |
| goldbar | флаг | Хотя бы один атрибут выпал на наилучшее возможное значение для типа, на мутаплазмиде Unstable. |
| brownbar | флаг | Хотя бы один атрибут выпал на наихудшее возможное значение для типа, на подходящем мутаплазмиде. |
| diamondbar | флаг | Как goldbar, но ролл сделан на мутаплазмиде Glorified. |
| item-exchange / auction | флаг | Только контракты этого типа. |
| no-multi-item-contracts | флаг | Только контракты, содержащие ровно один абиссальный модуль и ничего больше. |
| contracts-only | флаг | Исключает модули, выставленные только как объявления о продаже на MutaMarket. |
| without-other-items | флаг | Только контракты без посторонних предметов. |

Собранные в цепочку:

```
GET /api/modules/type/abyssal-ballistic-control-system/sort/price/asc/goldbar/contract-price/0-500000000
```

## Опрос новых объявлений

`sort/date-added/desc` упорядочивает по времени добавления текущего контракта
модуля на MutaMarket. Этот порядок только дополняется, поэтому опрос первой
страницы показывает новые модули без обхода всех страниц.

## Идентификация модуля

Сегмент пути, заканчивающийся цифрами, является поиском модуля по id предмета
EVE или по slug MutaMarket; всё остальное является списком в рамках типа. Оба
живут на одном пути.

```
GET /api/modules/1052842251186
GET /api/modules/abyssal-ballistic-control-system-1052842251186
```
