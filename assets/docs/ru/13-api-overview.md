# API MutaMarket

У MutaMarket есть публичный HTTP API для абиссальных модулей, в основном для
чтения: просмотр того, что продаётся, получение отдельного модуля со всеми
выпавшими атрибутами и его оценочной стоимостью, импорт модуля из EVE и
чтение справочных данных, лежащих в основе метрик качества роллов.

Ключ и аккаунт не нужны. Всё в формате JSON, по HTTPS, по адресу
`https://mutamarket.com/api`.

## Перед началом

- `POST /api/modules` обращается к ESI EVE и запускает ценовую модель при
  каждом запросе. Это занимает секунды. Не вызывайте его в плотном цикле.
- Отправляйте User-Agent, который вас идентифицирует, с контактным адресом.
- `/api/abyssal-type-statistics` меняется несколько раз в год. Кэшируйте его.

## Соглашения

Одиночные объекты обёрнуты в ключ `data`; справочные эндпоинты возвращают
простой массив.

Ошибки всегда представляют собой JSON-объект с полем `message`, а смысл
передаёт HTTP-статус:

| Статус | Значение |
|---|---|
| 400 | Запрос понят, но не может быть выполнен. |
| 404 | Такого модуля нет, или запрос не указал допустимый абиссальный тип. |
| 422 | Запрос корректно сформирован, но значение неприемлемо. `errors` называет поля. |
| 500 | Наша вина. |

```json
{ "message": "Please provide a valid type." }
```

## Какие эндпоинты стабильны

Публичными являются только эндпоинты, описанные в этом разделе, и только они
несут обязательство совместимости: мы не удалим поле и не изменим его смысл
без уведомления.

Всё остальное под `/api` обслуживает сам mutamarket.com и меняется без
предупреждения. Если вам нужно что-то, доступное только там, попросите об
этом, а не полагайтесь на него.
