# 获取帮助

如果某项功能无法使用，或你在这里找不到答案，Discord 是联系我们最快的方式。页脚有它的链接。

你也可以在游戏中通过 EVE 邮件联系 Nicolas Kion，或发送电子邮件至 [nicolaskion07@gmail.com](mailto:nicolaskion07@gmail.com)。

## 报告 Bug

说明你当时在做什么，以及实际发生了什么。附上你所在页面的 URL，因为它包含筛选条件，通常靠它就能重现问题。当问题是显示错误而非行为错误时，截图会有帮助。

发布到开发 Discord，或通过 EVE 邮件或电子邮件发送。

## 提出建议

同样的渠道。说明你想做什么，而不是你认为功能应该是什么样，会更有帮助，因为往往有比我们双方最初想到的更好的答案。

不是所有建议都会被实现，但所有建议都会被阅读。
