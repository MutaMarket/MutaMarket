# 收藏集

收藏集是一组有名称的模块。人们用它来跟踪正在寻找的模块、把一套装配归为一组、把一次突变改造的结果放在一起，或者向别人展示精选的一组模块。

[收藏集](/collections)列出社区创建的公开收藏集（可搜索），登录后下方还会显示你自己的。

## 创建收藏集

点击“创建收藏集”，输入名称，可选填写描述，然后选择谁可以看到它。

要添加模块，在网站任意位置右键点击模块，或使用其 `⋮` 菜单，打开“收藏集”，勾选你想加入的那个。你也可以从资产[位置](/documentation/selling-and-assets)或[工作台](/documentation/workbench-and-tools)批量构建收藏集。

名称、描述和可见性之后都可以在“编辑收藏集”下更改。

## 谁可以看到

| 可见性 | 谁 |
| --- | --- |
| 私有 | 只有你。这是默认值。 |
| 不公开 | 拥有链接的任何人，但它不会出现在任何地方。 |
| 公开 | 所有人。列在收藏集页面上，并可能出现在首页的推荐中。 |

无论可见性如何，只有所有者可以编辑收藏集。高级会员的收藏集在公开列表中排名更靠前。

要分享收藏集，复制其 URL 即可。重命名收藏集后链接仍然有效，并且在 Discord 和其他地方会生成预览图片。

## 收藏集页面

它显示创建者、可见性、描述，以及其中的每个模块，并带有常规筛选器。顶部的一栏合计整个收藏集：模块数量、各类标记条各有多少个，以及总价值和平均价值。

## 收藏集备注

作为所有者，你可以通过模块菜单中的“添加收藏集备注”为收藏集中的任意模块附加备注。所有能看到该收藏集的人都能阅读这些备注，所以适合用来解释价格、它所属的装配，或某个结果为什么有意思。

备注以批量方式编辑：想改多少条就改多少条，然后保存一次。

这些备注与个人模块备注不同，后者除你以外没人能看到。

## 从资产填充收藏集

“管理模块”按资产位置操作。对于每个装有深渊模块的容器或舰船，你可以把其内容加入收藏集、同步以使收藏集与该位置完全一致，或再次移除其模块。“移除所有模块”会清空整个收藏集。

## 自动同步

与其手动操作，不如开启自动同步并选择要跟踪的位置。每次导入资产时，收藏集都会根据这些位置中的内容重建。页面会显示上次运行的时间。

开启自动同步会清除收藏集当前的内容，并替换为这些位置中的模块，所以不要在手工整理的收藏集上启用它。关闭自动同步则会保留现有模块。
