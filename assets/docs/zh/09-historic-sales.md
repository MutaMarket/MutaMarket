# 历史成交

[历史成交](/historic-sales)是 MutaMarket 记录的每一笔深渊模块成交：模块、实际售价和时间。它是价格模型的训练数据，也是定价时最好的参照。

它需要[高级会员](/documentation/premium)。没有高级会员时，该页面会把你转到高级会员页面。

## 数据来源

MutaMarket 扫描已知空间的公开合同。当一份只包含单个模块的合同消失时，网站会向 EVE 的 API 查询它的结果。如果合同已完成，成交会按最终价格记录。如果合同过期或被删除，则不记录任何内容。

这就是数据集只包含单模块合同的原因。一份装有四个模块和一艘舰船的合同没有哪个价格能归属于任何一个模块。

## 搜索

与市场相同的基于 URL 的筛选器：类型、属性范围、成交价格，按价格或按日期排序，最新的在前。

通常你是从某个模块进入这里，而不是从零开始。任意模块工具栏或右键菜单中的“搜索历史成交”让你选择要匹配的属性和允许的偏差幅度，然后把你带到可比的成交。[模块页面](/documentation/module-details)上的“相似成交”标签页做的是同样的事，并已算好平均、最低和最高价格。训练数据面板会链接到该类型的成交记录。

## 为什么它与估值不一致

历史价格是单笔成交，所以包含了走运的和甩卖的。估值是对许多成交取平均的模型。

两者不一致时，成交记录是更可靠的证据。查看几笔近期的可比成交，判断你的结果在它们之间处于什么位置。
