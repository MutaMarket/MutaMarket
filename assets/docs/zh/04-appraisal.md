# 模块估价

有四种方法把模块导入 MutaMarket 并查看其价值。前三种都不需要账户。

**粘贴物品链接。**前往[估价页面](/modules/add)，粘贴链接，点击“估价”。在该页面上，你也可以不先点击输入框，直接按 Ctrl+V（Mac 上为 Cmd+V）。

要在游戏中获取链接，把模块拖入聊天窗口，发送消息，然后右键点击它并复制。

**用邮件发送。**在游戏中把模块链接发送给 **MutaMate**。你会收到一封回复邮件，内含每个模块的 MutaMarket 链接和估值。一封邮件中放多个链接也没问题。

**导入资产。**登录后，从[你的模块](/personal/modules)直接把模块从游戏内库存中拉取进来。

无论使用哪种方式，模块最终都会拥有自己的公开[页面](/documentation/module-details)，你也会进入该页面。

## 真正决定价格的是什么

属性只是其中一部分。

**所来源的模块**会带着自己的属性。X-Type MWDs 的价值比你预期的更高，因为它们没有电容惩罚，而这一点不会被任何突变改变。

**突变质体的供应**很重要。当某种突变质体稀缺时，即使是平庸的结果最终也能找到买家。

**已有多少在售**在大多数时候最重要。拥挤的市场压低价格，而对没人特别想要的模块压得最狠。

所以估值只是起点。要给一个模块正确定价，请在模块页面上使用“搜索相似”或“搜索最便宜”，看看实际挂牌的情况。有了[高级会员](/documentation/premium)，你还可以更进一步，通过[历史成交](/historic-sales)和“相似成交”标签页与真正售出的模块对比。

## 估值是如何得出的

每个深渊类型都有自己的模型，即一个用真实成交训练的随机森林。

训练数据是 MutaMarket 追踪到的单模块合同成交，并以基础模块价格作为参考点。输入是模块的突变属性值，目标是成交价格。随机森林在数据的不同切片上构建大量决策树并取平均，从而避免任何一棵树过拟合。

一个类型需要 50 条已记录成交才能获得模型。低于此数时，其模块会显示还差多少，而不是价格。随着新成交的加入，模型会重新训练。

每个预测都会在模块页面上附带自己的质量指标，让你知道该信任它到什么程度。[模块页面](/documentation/module-details)对每项指标都有解释。

## 它在哪里会出错

模型只知道已经售出的东西，所以它落后于市场，滞后时间取决于成交积累的速度。在情况快速变化时这一点影响最大：改变主流配置的版本更新、突然的供应过剩、变得稀有的突变质体。

它恰恰在你最需要的地方最弱。稀有模块的可比成交很少。不寻常的属性组合可能几乎没有。完美结果按定义就是模型几乎没见过的东西。高价值模块是 ISK 误差最大的地方，也是你无论如何都应该自己做研究的地方。

一笔反常的成交就能拉动一个类型的数据，而且 MutaMarket 只能看到它看得到的合同，所以数据存在空缺。

用它来大致判断你所处的价格区间，然后去查看市场。
