# 工作台与工具

## 工作台

工作台用于并排比较模块。在网站任意位置右键点击模块并选择“添加到工作台”。它浮在页面之上（移动端为底部面板），并随你在各页面间移动，把你的模块并排显示，附带合计价格、伤害模块组合的 DPS 估算，以及按类型的细分。

它最多容纳 25 个模块，并需要账户。

“分享”复制一个指向它的链接。打开该链接的人会看到同样的模块，并可以一键把它们拉入自己的工作台。“保存”把内容转为一个新的私有收藏集。“清空所有模块”将其清空。

## 突变计算器

[计算器](/calculator)回答你在花钱之前应该问的问题：概率有多大。

选择一个模块类别，可选按元组或元等级缩小范围，然后设置你想要的属性范围。它会列出所有可能产出该结果的基础模块和突变质体组合，以及单次突变落在你所有范围内的概率，以百分比和“N 分之一”两种形式表示。无法达到你目标的组合会明确说明。

旁边是期望成本：基础模块加突变质体，除以概率，也就是平均而言达到该结果应该花费的成本。悬停可查看明细。

价格来自 Jita 日均价，所以会变动。

你可以从 Pyfa 导入模块作为起点，查询条件保存在 URL 中，所以概率搜索可以分享或加入书签。

在据此行动之前，值得先读一下[突变指南](/documentation/rolling-guide)。

## Omega 计算器

[Omega 计算器](/omega-calculator)计算叠加折扣后 Omega 每月的实际成本：在打折时购买 PLEX，然后在 Omega 促销期间在新伊甸商店中兑换 Omega。

选择一个 PLEX 套餐，输入当前的 PLEX 和商店折扣，如果你使用 MarkeeDragon 的 3% 优惠码也可以应用。它会给出每月的实际成本、你能负担多少个月、你节省了多少，以及一张对比各种折扣组合的表格。

## 书签

书签保存的是页面，而不是模块。侧边栏中的书签卡片有一个“添加当前页面”按钮，可以用你选择的名称保存你所在的位置。

因为每个筛选条件都保存在 URL 中，给搜索加书签就保存了整套筛选设置。这正是书签的意义：你经常回来看的市场搜索、一个计算器查询、一个位置。需要账户。

## 备注

任意模块菜单中的“添加备注”会为它附加一条私人备注。其他人永远看不到，并且模块出现在任何地方时它都会跟随显示。

选择它会为整个页面开启备注编辑：每个模块都会出现一个输入框，所以你可以一次写多条，然后用底部的操作栏全部保存。清空输入框并保存会删除该备注。

收藏集备注的用法相同，但是共享的。它们位于[收藏集](/documentation/collections)中。

## 要价

“设置要价”位于你已挂牌出售的任意模块的菜单中。它的用法与备注相同：你拥有的每个模块都会出现一个价格输入框，一次保存全部设置。留空会移除其价格，买家则回到通过[报价](/documentation/offers)自行给出数字的方式。

出售页面有一个“编辑要价”按钮，可以不经过菜单直接进入同一模式。
