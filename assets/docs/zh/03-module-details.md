# 模块页面

每个模块都有自己的页面。在[市场](/modules)上点击任意挂牌即可打开。页面包含完整的属性明细、价格模型给出的估值、你最常用的工具，以及与之相似的模块在市场上的表现。

页面分为三部分：左侧的卡片、旁边的面板，以及下方的标签页。

## 卡片

卡片就是模块本身：名称、所来源的模块、所用的突变质体，以及每个突变属性的结果数值、相对基础值的变化幅度，和一根显示结果在可能范围内落点的条。

如果模块在合同中，卡片会在估值旁显示合同价格。`+N` 标记表示合同中还包含其他模块。

属性行带有颜色。绿色或红色表示结果优于或劣于基础值。金色、钻石和棕色标记达到类型极值的结果，[浏览市场](/documentation/browsing-the-market)对此有说明。在显示设置中开启属性评分后，每一行还会显示一个带符号的评分，表示结果在范围内的深入程度。

## 它值多少

卡片旁的面板显示模块的改造者，以及价格模型的预测。

| 字段 | 含义 |
| --- | --- |
| 估值 | 预测价格，以 ISK 计。点击可复制。 |
| ±% | 模型在此模块类型上的平均误差。 |
| 评估时间 | 此模块的估值最近一次计算的时间。 |
| 置信度 | 从极低到极高，来自模型的 R² 分数。 |
| 偏差评分 | 训练数据对各源类型覆盖的均匀程度。 |
| 平均误差（MAE） | 平均绝对误差。越低越好。 |
| 最近训练 | 此类型的模型最近一次重建的时间。 |
| 训练数据 | 每个源类型的已记录成交数。少于十条会标为红色。 |

一个类型需要 50 条已记录成交才能训练模型。低于此数时没有预测，面板会改为显示还差多少。

这些模型可能错得离谱。把这个数字当作起点，再去查看相似模块的实际售价。[估价指南](/documentation/appraisal)说明了它们在哪些情况下会失准。

## 工具栏

| 按钮 | 作用 |
| --- | --- |
| 搜索此类型 | 筛选为此模块类型的市场。 |
| 搜索相似 | 选择要匹配的属性和容差，然后查找在售的、结果相近的模块。 |
| 搜索最便宜 | 同上，按价格从低到高排序。 |
| 搜索历史成交 | 同上，但针对历史成交而非当前挂牌。需要高级会员。 |
| Pyfa | 以 Pyfa 可识别的格式复制属性。 |
| 复制物品链接 | 复制一个可粘贴到游戏内记事本的链接。 |
| 复制合同链接 | 复制合同链接。没有合同时不可用。 |
| 在游戏中打开合同 | 在你的 EVE 客户端中打开合同。没有合同时不可用。 |
| 分享模块 | 分享或复制本页面的链接。 |
| 更多操作 | 复制或下载模块的分享图片。 |

三个搜索菜单的用法相同。勾选你关心的属性，设置允许的偏差幅度，然后搜索。“全选”和“全部清除”可以一次切换所有属性。

## 卡片菜单

右键点击卡片，或使用其 `⋮` 按钮，可查看其余操作。登录后还会多出：

**收藏集**把模块放入你的某个[收藏集](/collections)或新建一个，并可以在那里为它留下备注。

**工作台**把模块加入或移出你的对比[工作台](/documentation/workbench-and-tools)。

工具栏中的复制和导出操作在这里也有。

**添加备注**为模块附加一条私人备注。只有你能看到，并且模块出现在任何地方时都会显示在卡片下方。

**设置要价**出现在你已挂牌出售的模块上。这两项都支持批量操作：菜单开启编辑模式，页面底部的操作栏负责保存。[备注与要价](/documentation/workbench-and-tools)有详细说明。

## 标签页

**源类型**对比该突变质体可应用的每一个模块，从 T1 到官员级。对每个突变属性，它显示该源模块的基础值和此结果与之的比较，以及每个源模块当前的价格。这是判断你的结果是否真的胜过直接购买势力版本的最快方法。

**合同历史**是 MutaMarket 见过的、涉及此模块的每一份合同：发布者、时间、是否包含其他物品、结果如何，以及价格。当前的合同以“未完成”状态排在最上方。

**相似成交**需要[高级会员](/documentation/premium)。它显示结果与此模块相近且实际售出的模块，以及平均、最低和最高价格。没有高级会员时只能看到模糊预览。

## 购买

如果有人把模块直接挂牌在 MutaMarket 上，卡片上的价格可以点击。它显示卖家的要价，或在卖家未设置要价时显示“提出报价”。点击会打开一个对话框，让你给卖家发消息。如果你已经对它有一个未结的报价，卡片会改为显示“前往报价”。[报价](/documentation/offers)介绍了完整流程。

在游戏内合同中的模块通过合同购买。使用“在游戏中打开合同”或复制链接。
