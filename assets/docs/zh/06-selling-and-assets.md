# 出售与资产

有两种方式把模块展示给买家，它们相互独立。

## 游戏内合同

在游戏中创建公开合同，物品交换或拍卖均可。MutaMarket 每 30 分钟扫描一次已知空间的公开合同，并列出其中发现的所有深渊模块。你不需要账户，也不需要任何设置。拍卖出价和你自己角色的合同刷新得更频繁。

## 在 MutaMarket 上挂牌

另一种方式是把你库存中的模块设为可见，让买家可以向你发送[报价](/documentation/offers)。交易本身仍然在游戏中进行，通过合同或你们双方约定的直接交易。

登录并前往[出售模块](/sell/modules)。点击“开始导入”拉取你的资产。这需要读取资产的权限，如果你尚未授予，网站会向你请求。

然后把你想出售的模块放进容器或舰船。散放在空间站机库里的模块不会显示。点击“选择模块”，找到该容器，并开启其可见性。容器内的所有模块都会变为公开。

要为它们定价，使用出售页面顶部的“编辑要价”，或模块菜单中的“设置要价”。两者都会为每个模块开启一个价格输入框，底部的操作栏一次性全部保存。没有价格的模块会向买家显示“提出报价”，由他们自己给出数字。

可见性刻意设计为按容器或按舰船，从不按整个空间站，并且只有实际装有深渊模块的容器才会出现在列表中。这样可以避免你意外暴露整个机库。

公开后，你的模块会出现在市场、出售页面和你的角色页面上。

## 导入资产

[你的模块](/personal/modules)有同样的“开始导入”按钮，并在运行时显示进度。它通过 EVE 的 API 读取你的资产，找出容器和舰船中的深渊模块，并把它们加入你在这里的库存。

首次导入后，它会自动刷新，大约每六小时一次，所以你应该不需要再手动操作。如果你授予了军团访问权限，军团机库也会一并导入。

如果导入无法进行，请退出 MutaMarket 再重新登录。这会更新与 EVE 的连接，能解决大部分问题。如果仍然失败，请到 Discord 上告诉我们。

## 你的模块

[你的模块](/personal/modules)列出你拥有的所有深渊模块。它有常规筛选器，外加三个位置筛选：不含合同、不含已装配、不含资产。从任意模块，你都可以为它估价、放入收藏集或工作台，或跳转到它的合同。

## 在游戏中找到模块

把鼠标悬停在模块的位置上可查看精确指引。简短版本：打开它所指的容器，按类型排序（这是默认排序），搜索类型名称，然后向下数到 MutaMarket 显示的位置编号。位置 4 表示从上往下第四个。

如果你把库存调整为每行十个物品，提示框还会给出行号和列号。

## 位置

[位置](/locations)是一棵可搜索的树，包含你存放深渊模块的每个空间站、建筑、容器和舰船，并附有各自的数量。打开一个位置，可以用常规筛选器浏览其中的内容。

每个位置上都有一个“创建收藏集”按钮，可以把其中的所有模块快照为一个新的私有[收藏集](/documentation/collections)。

## 你的合同

[你的合同](/personal/contracts)汇总你在所选日期范围内的深渊合同：未完成、已完成和历史合同。它在一张可搜索的表格上方合计你的收入、支出、仍未完成的合同及其价值，以及你的利润。“刷新合同”会强制重新扫描。

有些合同返回时缺少数据。这是 EVE 的 API 的问题，而不是我们这边的问题，我们无法修复。

要在游戏中打开合同，右键点击模块并选择“在游戏中打开合同”。或者复制合同链接并粘贴到游戏内记事本中。链接无法粘贴到聊天中。

## 你的统计

[你的统计](/personal/stats)汇总你所有角色突变改造过的模块：模块数量、制作成本，以及当前价值，并按类型和角色细分。

成本是基础模块加突变质体按今日 Jita 均价计算的结果，而不是你实际支付的金额，所以两个数字都应视为估算。
