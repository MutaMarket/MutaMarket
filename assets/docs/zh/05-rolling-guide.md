# 模块突变

突变改造是赌博。大多数时候它会亏钱，大多数时候你更应该直接从[市场](/modules)购买你真正想要的模块。如果你无论如何都要改造，这里是常见的失误。

## 值得改造的模块

**meta 模块上的 Gravid 和 Decayed 突变**是自用的。卖掉它们非常困难，你应当默认卖不出去，只在自己想用的时候才改造。

**有些基础模块根本不值得碰。**一个完美结果的 T2 warp disruptor 仍然不如一个 30km 的势力 disruptor，所以上限低于别人直接能买到的东西。花钱之前先查一下替代品的价格。

**官员级模块是弄清这一点的昂贵方式。**上限确实存在，但如果结果落在一个便宜得多的势力模块已经覆盖的范围内，它的大部分价值就已经毁掉了。

## 用哪种突变质体

粗略规则是：meta 模块用 Decayed 和 Gravid，高价值模块用 Unstable，这样突变质体的成本与被改造的模块保持相称。

有两种情况会打破这条规则。

有时你追求的属性只有通过某一种特定的基础模块和突变质体组合才能达到，这时规则不适用，研究才适用。[计算器](/calculator)会告诉你，你设想的组合能否产出你想要的结果。

另外，有些 Unstable 突变质体比它们所应用的模块还贵。Damage Controls 和 Large Cap Batteries 是常见例子。除非你在追求某个特定的高价值结果，否则突变质体会吃掉利润。
