# 高级会员

高级会员用 ISK 在游戏内支付。不涉及真实货币，也不需要输入银行卡。

它为你解锁[历史成交](/documentation/historic-sales)，即任意模块类型的每一笔已记录成交，以及模块页面上的“相似成交”标签页，显示实际售出的可比结果及其平均、最低和最高价格。有了这两样，就是猜价格和知道价格的区别。

它还会把你的模块排在收藏集和角色页面的最前面，让你的角色和收藏集在公开列表中排名更靠前，并让你的角色名在全站显示为金色。

高级会员属于角色，而不是账户。哪个角色发送 ISK，哪个角色就获得高级会员。

## 费用

| 方案 | 价格 |
| --- | --- |
| 1 个月 | 1 亿 ISK |
| 12 个月 | 10 亿 ISK，相当于免费两个月 |

[高级会员页面](/premium)始终显示当前价格。

## 支付

从应获得高级会员的角色，在游戏中把 ISK 发送给[高级会员页面](/premium)上指明的角色，也就是 MutaMate。

钱包每分钟检查一次，但 EVE 的 API 可能会延迟一段时间才显示新的捐赠，所以请最多等待一小时。到账后你会收到一封游戏内邮件，高级会员立即生效。

如果你发送的金额不足一个月，也不会丢失。捐赠会累积，余额够一个月时高级会员即刻开始。邮件会告诉你当前余额和还差多少。

剩余时间显示在侧边栏的高级会员卡片中。快到期时你会收到邮件，如果关联了 Discord 则会收到 Discord 消息。

## Patreon 不是高级会员

在 Patreon 上支持本项目并在[设置](/settings)中关联，可以去除广告。它不会解锁历史成交、相似成交、优先排序或金色名称。这些只能通过 ISK 高级会员获得，并且是按角色计算的。
