# 浏览市场

[模块页面](/modules)显示当前在售的模块。这包括公开的游戏内合同（物品交换和拍卖都有），以及玩家直接在 MutaMarket 上挂牌的模块。每页三十个。

每张卡片显示源模块和所用的突变质体、每个突变属性的数值及其相对基础值的变化幅度、每个属性一根显示突变结果落点的条，以及价格。合同挂牌会在物品交换或拍卖图标旁显示合同价格，并附上估值。如果一份合同包含多个模块，卡片上会带有一个 `+N` 标记表示其余的模块。

点击卡片可打开其[详情页](/documentation/module-details)。右键点击卡片，或使用 `⋮` 按钮，可使用快捷操作：搜索相似、最便宜或历史成交，分享，打开或复制合同，复制 Pyfa 数据或物品链接。登录后还可以使用收藏集、工作台、备注，以及在自己的挂牌上设置要价。

## 筛选器

筛选条件保存在 URL 中，所以你构建的任何视图都可以加入书签、分享或稍后重新打开。`/modules/type/500mn-abyssal-microwarpdrive/sort/price/asc` 就是全部 500MN abyssal MWD，按价格从低到高排列。

| 筛选器 | 界面中 | URL 中 |
| --- | --- | --- |
| 类型 | 类别选择器 | `type/<type-name>` |
| 元组 | 元组：全部、T1、T2、剧情、势力、官员、死亡空间 | `meta-group/<group>` |
| 元等级 | 元等级 | `meta-level/<n>` |
| 属性 | 选定类型后出现的范围滑块 | `attributes/<name>/<min>-<max>/...` |
| 排序 | 价格、估值或任意属性，升序或降序 | `sort/<field>/<asc\|desc>` |
| 价格 | 价格滑块，100 万到 1000 亿 ISK | `contract-price/<min>-<max>` |
| 估值 | 估值滑块 | `estimated-value/<min>-<max>` |
| 合同类型 | 全部、物品交换或拍卖 | `item-exchange` 或 `auction` |
| 仅合同 | 隐藏直接挂牌 | `contracts-only` |
| 多物品合同 | 关闭时仅显示单物品合同 | `no-multi-item-contracts` |
| 个人模块 | 包含你自己导入的资产。需要账户 | `with-personal-modules` |
| Jita | 仅显示位于 Jita 4-4 的模块 | `in-jita` |
| 金色、棕色、钻石条 | 位于“其他”下 | `goldbar`、`brownbar`、`diamondbar` |

筛选面板中还有一个“导入 Pyfa 模块”按钮，可以把 Pyfa 中的模块导入进来，并搜索属性相近的模块。

## 金色、棕色和钻石条

这些标记表示突变结果达到了该深渊类型所能达到的极值，范围涵盖所有能产出该类型的突变质体。

一个模块只有最强的等级才能获得标记。在同一模块上，Decayed 和 Gravid 不如 Unstable，所以它们永远不会得到标记，Glorified Decayed 和 Glorified Gravid 也不会。Unstable 可以，Exigent 和 Radical 也可以，因为它们之上没有更强的等级。

**金色条**表示最佳可能结果。**钻石条**表示在 Glorified 突变质体上获得的同样结果。**棕色条**表示最差可能结果。

无法变化的属性不会有任何标记。

在卡片上，这些标记以金色、钻石蓝或棕色同时显示在数值和属性条上。“其他”筛选器会把列表缩小到至少有一个属性带有你所选标记的模块。

## 更改显示方式

列表上方的选项会在多次访问之间保留。

**显示**在网格、列表和表格之间切换。

**属性条**更改条所度量的内容：默认绘制结果在你的突变质体范围内的落点，类型按整个深渊类型归一化，绝对使用原始数值，无则隐藏属性条。

**显示属性评分**为每个属性加上突变质量评分。

## 市场统计

筛选区域的统计面板显示实时总数：数据库中有多少个模块，各类标记条各有多少个，有多少份合同处于活跃状态（按物品交换和拍卖分列），以及过去一小时、一天和一周内新出现了多少个模块。

## 全部模块

[全部模块](/all-modules)涵盖 MutaMarket 已知的所有模块，而不仅是在售的。这里不涉及合同，所以筛选器较少：类型和元组筛选、标记条开关、估值和属性范围。想知道究竟存在哪些突变结果，就来这个页面。

## 角色

[角色](/characters)列出所有在 MutaMarket 上直接出售模块的人，高级会员卖家排在前面。打开一个角色，可以看到其公开模块（可像其他列表一样筛选）、简介，以及其选择公开显示的 Discord、Twitch 或 Patreon 账户。

切换到“创建”筛选器后，页面显示的是该角色突变改造出的模块，而不是在售的模块。

在你自己的页面上，可以编辑简介，并选择公开哪些资产位置。

## 统计

[统计](/statistics)按突变改造过的深渊模块数量对角色排名。你可以把排名缩小到某一个模块类型，或按名称搜索角色。点击某人的模块数量会打开其页面，并筛选为其创建的模块。
