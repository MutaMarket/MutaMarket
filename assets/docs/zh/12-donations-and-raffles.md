# 捐赠与抽奖

MutaMarket 是免费的。如果你想有所回馈，有三种方式。

在游戏中把 ISK 发送给 **MutaMate**。[捐赠页面](/donations)有一个复制名称的按钮。

购买[高级会员](/documentation/premium)。这才是真正覆盖运营成本的来源，而且你能得到相应的回报。

在 Patreon 上支持并在[设置](/settings)中关联，这会为你去除广告。

捐赠页面有三个列表：过去十四天的捐赠榜、历史名人堂，以及最近的捐赠。

## 抽奖

MutaMarket 向网站用户赠送可兑换的 EVE 代码。无需参与，也无需报名。

每小时进行一次抽取，最多抽出五份奖品。要符合资格，你需要在过去七天内在网站上活跃，并且当前没有持有奖品。管理员被排除在外。

如果你中奖，在你使用网站时会出现一个弹窗。你需要在下一个整点之前回应，也就是最多一小时，之后奖品会回到奖池。领取或放弃均可。

领取后，代码位于[设置](/settings)中的“你的奖品”下，带有显示切换、复制按钮，以及指向 EVE 代码激活页面的链接。

你一次只能持有一份奖品。
